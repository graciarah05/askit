# 대학생이 Askit을 쓸 이유와 검수 범위

기준일: 2026-11-10. 이 문서는 조사 근거, 제품 가설, 실제 관측을 구별한다. 아직 학생 대상 사용성 실험이나 재방문 측정을 하지 않았다.

## 조사에서 확인한 사실

- [HEPI 2026](https://www.hepi.ac.uk/reports/student-generative-ai-survey-2026/): 2025년 12월 영국 전일제 학부생 1,054명, 인구학적 가중 조사. AI 사용 95%, 평가 과제 보조 사용 94%. 개념 설명·학술 자료 요약·아이디어 구조화가 주요 학업 용도다. 자기보고 조사이므로 실제 학습 향상이나 한국 학생의 이용 비중으로 해석하지 않는다. Kortext 후원 연구다.
- [Anthropic 학생 사용 분석](https://www.anthropic.com/research/anthropic-education-report-how-university-students-use-claude): 고등교육 이메일 계정 대화에서 추린 574,740개 교육 관련 대화. 교육 콘텐츠 작성·개선 39.3%, 기술 설명·풀이 33.5%, 데이터 분석·시각화 11.0%. 학생 수가 아닌 대화 비중이며 Claude 이용자와 컴퓨터과학 전공 편향이 있다. 모든 AI·모든 대학생의 수요로 일반화할 수 없다.
- [Jisc 2025](https://www.jisc.ac.uk/reports/student-perceptions-of-ai-2025): 고등·추가교육 학생 173명의 토론과 7개 설문 1,274개 응답을 종합했다. 글쓰기·연구·필기·복습·발표 활용과 함께 과목별 실용적 지원, 출력 검증, 개인정보, 과도한 의존에 대한 요구가 나타났다. 질적 결과이며 전국 대표 비율이 아니다.
- [국내 연구, 박상훈 2025](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART003236169): 충북 한 대학 99명 대상. 자료 분석·창의 작업·개별 학습 등 활용 경험을 보고한다. 공개 초록 범위만 확인했으며 전국 대표성·분야별 정확한 비중·인과 효과를 주장할 수 없다.

검토한 조사만으로 ‘이미지 이용의 대다수는 레퍼런스 수정’이라는 비율은 확인되지 않았다. 그러나 레퍼런스 응용은 사용자가 지정한 중요한 검수 시나리오이므로 별도로 검증한다. 복잡한 과제일수록 프롬프트가 반드시 더 큰 효과를 낸다는 단조 관계도 이 조사들은 증명하지 않는다.

## 제품 판단 — 조사에서 도출한 가설

학생이 이미 AI를 쓰는 상황에서 ‘AI에 질문을 대신 써 주는 사이트’만으로 방문 이유는 약하다. Askit의 후보 가치는 자료·과제 조건·참고 디자인의 역할을 분리하고, 놓치기 쉬운 제약을 반영해 적절한 Google 도구와 결과 확인까지 연결하는 데 있다. 기존 Gemini/Notebook/Canvas의 자체 기능만으로 충분하면 Askit의 추가 입력과 화면 이동은 비용이다.

| 상황 | 직접 AI 사용으로 충분할 때 | Askit이 도움을 줄 수 있는 지점 | 채택 조건 |
|---|---|---|---|
| 개념·짧은 요약 | 질문과 원하는 답이 명확함 | 현재 이해·오답을 반영한 연습 설계 | 답을 먼저 공개하지 않고 스스로 적용할 기회 제공 |
| 여러 자료 비교 | 한 문서의 핵심만 필요함 | 표본·단위·시점·충돌·누락을 함께 비교 | 수치 재계산과 원문 인용 정확, 입력 부담에 상응하는 개선 |
| 평가 기준 있는 과제 | 이미 완성된 지시문으로 잘 작동함 | 과제 안내·내용 자료·형식 참고를 연결 | 채점 조건 누락 감소, 미확인 사실 추가 없음 |
| 참고 포스터 응용 | 단순 문구 변경으로 충분함 | 분위기·배치만 참고하고 새 행사 정보 적용 | 문구/로고 오염 없음, 요구 정보 정확, 실제 파일 확보 |
| 카드뉴스 | 단일 이미지면 충분함 | 페이지별 메시지·공통 디자인·순서 유지 | 별도 이미지 수, 순서, 크기, 일관성 검증 |
| 여러 장면 영상 | 한 장면의 설명이 명확함 | 도구 길이 제한에 맞춘 장면·연속성·오디오 설정 | 시간 합계, 참고 연결, 실제 움직임 검증 |

재사용 이유는 매번 다른 과제 자료·평가 기준을 적용하고 이전 조건을 다시 쓸 수 있는지에 달려 있다. 커뮤니티 체류나 가입 전환을 학습 효용의 증거로 대체하지 않는다.

## 검수 기준

- 정보 동등성: 일반 프롬프트에도 동일 자료·목표·제약을 제공. 일반 쪽을 일부러 모호하게 만들지 않는다.
- 기준 사전 고정: 생성 전에 사례별 참/거짓으로 판별 가능한 체크 항목, 예상 계산, 치명적 오류를 기록한다.
- 결과와 절차 분리: 내용 정확도, 조건 충족, 파일 완성, 사용자가 해야 할 입력/설정/재첨부를 각각 기록한다. 미적 선호는 객관 점수에 합산하지 않는다.
- 최초/수정 후 분리: 최초 출력과 실패를 보존하고 재검수 결과만으로 승률을 부풀리지 않는다.
- 중단 기준: 핵심 수치 오류·없는 근거·요청하지 않은 사실·불가능한 실행 안내가 있으면 해당 사례를 모범 결과로 공개하지 않는다.
- 제품 채택: 적어도 중요 오류 하나를 줄이거나 결과 완성 단계를 줄여야 유용성 후보로 인정한다. 동률인데 절차가 늘면 차별성 부족으로 판정한다.
- 한계: 같은 작성자의 탐색적 평가이며 독립·블라인드 평가, 통계적 우월성 검증, 학생 사용자 실험이 아니다. 사용자 대상 과제 완료율·시간·수정 횟수·부담 측정이 별도로 필요하다.

## 현재까지의 기본 검수

실제 Google 도구에서 I1(텍스트 포스터), I2(원본 일부 색 변경), V1(8초 영상), D1(두 설문 비교) 양쪽 출력을 확보했다. 이들은 연결과 조건 보존을 점검하는 기본 사례이며 제품 수요를 대표하지 않는다. 자료·출력은 qa/paired에 보존한다.

- I1: 양쪽 모두 핵심 문구·책 한 권을 표현했다. 내려받은 화면 표시용 이미지는 둘 다 825×1024였다. 원본 다운로드 크기와 혼동하지 않으며, 이 파일만으로 생성 원본의 비율 오류를 확정하지 않는다. Askit 쪽 장식이 적다는 관측을 품질 우위로 계산하지 않는다.
- I2: 양쪽 모두 원을 청록색으로 바꿨지만 화면 표시용 다운로드는 820×1024로 입력 원본 800×1000과 다르다. 생성 원본 해상도는 별도 미검증이다. 문구와 배치는 시각적으로 유사하지만 원본의 픽셀·크기 보존을 통과로 처리할 수 없다.
- V1: 양쪽 원본 720×1280, 24fps, 약 8초를 확보했다. 전체 재생 및 0.5초 간격 프레임을 확인했다. 물소리만 있는지에 대한 청취 판정은 아직 미검증이다. 분위기 차이를 점수로 만들지 않는다.
- D1: 양쪽 모두 60%/40% 계산과 일반화·인과 해석의 제한을 지켰다. Askit은 요청한 답 외 후속 제안을 줄였지만, 자체 자료 번호와 실제 인용을 이중 표기해 복잡해졌다. 실제 인용도 있었으므로 ‘가짜 출처만 생성했다’고 주장하지 않는다.
- V2 사전 확인: 사용자가 16:9라고 써도 UI는 9:16을 안내했다. 프롬프트 본문은 16:9였으므로 UI/프롬프트 불일치다. 생성 비용을 더 쓰기 전에 수정했다.

복합 과제 D3는 전체 평균과 하위집단 추세가 다르고 대안의 예산·직원 시간 제한을 동시에 적용하는 과제다. 정답 기준은 D3-protocol.md에 결과 생성 전에 기록했다. Pinterest 로그인 후 P1·P2의 동일 정보 비교와 수정 후 재검수를 수행했다. 구체적인 실패·수정·재검수는 REFERENCE-FIDELITY-AUDIT.md와 qa/paired/reference-review.html에 기록한다. 기존 단순 텍스트/파일 체크만으로 레퍼런스 충실도가 높다고 판단하지 않는다.
