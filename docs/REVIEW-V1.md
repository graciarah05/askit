# Askit 수정·검수 기록

확인일: 2026-11-09. 기존 v4/v5는 보존하고 `askit-release`에 별도 제작했습니다.

## 판단과 변경

Askit의 첫 방문 목적은 **지금 막힌 과제의 요청을 빠르게 정리해 실제 도구에서 시작하는 것**으로 한정했습니다. 계속 방문할 이유는 저장한 요청 재사용, 새 과제에 맞는 조건 수정, 학생끼리 실제 사용 과정을 나누는 기능입니다. 실제 학생 사용자 연구를 하지 않았으므로 방문 의사·재방문율·가입률이 검증됐다고 주장하지 않습니다.

- 서비스명과 헤더는 제공받은 Askit 원본 로고로 변경했습니다. Figma 원본 심볼/워드마크·아이콘·배경을 사용합니다.
- Wanted 스타일을 덮어쓰는 방식 대신 스타일 파일을 새로 작성했습니다. 최종 공개 폴더의 Wanted 참조는 0건입니다.
- 체험·예시 게시글·인위적인 작성자·사용 성과를 제거했습니다. 활용 방법은 사용법으로 제공합니다. 학습에서 필요한 ‘예시’라는 표현까지 삭제해 설명력을 떨어뜨리지는 않았습니다.
- 요청한 GSA 문구, 추천 링크 설명, 안내 숨기기, Dreamland 부제는 제거했습니다. 학생 혜택 버튼은 첫 화면 안으로 이동했습니다. 실제 신청에 필요한 자동 유료 갱신 조건은 버튼 전에 유지합니다.
- 주요 선택 항목은 모두 직접 입력을 허용합니다. 기본 사용은 주제 하나와 형식 선택으로 끝납니다. 맥락·언어·추가 조건은 접힌 영역에 두었습니다.
- 학생 커뮤니티는 운영진 문의 공간이 아닙니다. 공유형 글·활용 사례·이미지·댓글·답글·좋아요·보관·신고를 별도 Supabase 구성으로 준비했습니다.

## 판정 기준

점수 합산 대신 아래 조건을 각각 통과해야 하는 기준으로 삼았습니다.

| 분야 | 통과 조건 | 확인 방식 |
|---|---|---|
| 입력 부담 | 일반 작업은 주제 1개, 자료 작업은 전달 방법만으로 진행 가능. 추가 질문은 선택 사항 | 7개 작업을 실제 브라우저에서 실행 |
| 개인화 | 모든 주요 드롭다운에 직접 입력. 빈 직접 입력은 명확히 안내 | 7개 작업 × 형식·맥락 2개·언어 |
| 자료 경계 | 첨부 방식으로 바꾸면 이전에 붙인 자료를 전송용 요청에 넣지 않음 | 입력 전환 회귀 검사 |
| 요청 품질 | 자료와 지시 구분, 조건 우선순위, 작업별 결과 형식, 근거·검토 조건 | 공식 문서 대조 + 실제 Gemini 비교 |
| 사용 연속성 | 수정한 프롬프트가 복사·저장·새로고침 후 유지 | 브라우저 실행 |
| 실패 복구 | 복사 거절·팝업 차단·글 등록 실패가 거짓 성공으로 끝나지 않음 | 실패 상황 강제 실행 |
| 공유 권한 | 타인 글 수정·삭제와 타인 이미지 폴더 업로드 차단 | PostgreSQL 권한 검사 |
| 화면 | 320·390·430·768·1440px 가로 넘침 없음, 핵심 화면 자동 WCAG A/AA 위반 없음 | 화면 조작·스크린샷·axe |
| 광고 부담 | 핵심 작업 중 가입 강요·모달·기능 잠금 없음 | 화면/분기 검사 |
| 사실성 | 연결하지 않은 API·서버·가입 완료를 완료로 표시하지 않음 | 화면과 배포 설정 확인 |

## Gemini 공식 지침의 적용

[Google의 프롬프트 지침](https://ai.google.dev/gemini-api/docs/prompting-strategies)은 명확한 요청, 일관된 구분, 필요한 맥락과 결과 형식, 작업에 맞는 예제를 강조합니다. 이를 바탕으로 지침 → 자료 → 사용자 설정 → 결과 조건 → 근거 점검 순서를 적용했습니다. 문장을 무조건 길게 늘리는 방식은 쓰지 않았습니다.

- 요약: 대상·기간·수치·예외를 유지하고, 전체 조사 대상과 일부 응답을 혼동하지 않도록 명시합니다. 근거는 요약 문장 안에 붙입니다.
- 발표: 슬라이드별 구성·근거·화면·시간을 연결하고 총 시간·장수를 확인합니다. 과제 지시문이 선택한 기본 분량보다 우선합니다.
- 퀴즈: 제공 자료만 사용하고, 한 문제씩 선택했다면 답하기 전에 정답이 나오지 않도록 합니다.
- 보고서: 질문·목차·논거·조사 계획을 구분하고 확인하지 않은 논문·저자·DOI 생성을 금지합니다.
- 영상: 시간과 촬영 여건을 맞추고 실제 영상 파일을 만든 것처럼 말하지 않도록 합니다.

[Thinking 문서](https://ai.google.dev/gemini-api/docs/thinking)에 맞춰 내부 사고 과정 출력을 요구하지 않습니다. [검색 근거 연결](https://ai.google.dev/gemini-api/docs/google-search)은 실제 도구 설정이 필요하므로 요청문만으로 검색이 활성화된다고 표시하지 않습니다. [모델별 지침](https://ai.google.dev/gemini-api/docs/gemini-3)에 따라 특정 temperature나 과거 모델명을 고정하지 않았습니다.

## 실제 Gemini 비교

개인정보 없는 동일한 입력을 일반 요청과 Askit 요청에 각각 전달했습니다. 독립 Chrome, 비로그인 Gemini, 화면 표시 Flash-Lite 환경입니다. 3개 과제의 두 방식 6회와 요약 수정 후 1회, 총 7회 응답을 기록했습니다. 단일 실행이며 모델의 정확한 버전·추론 설정을 통제할 수 없었습니다. 통계적 우위나 모든 학생 과제의 품질 보장은 아닙니다.

| 과제 | 일반 요청 | Askit 요청 | 판정 |
|---|---|---|---|
| 발표: 기본 5분·5장, 과제 조건 7분·6장 | 6장이지만 첫 설명은 5분으로 작성. 시간 배분 없음 | 6장, 1+1+1.5+1.5+1+1=7분, 총량 표시 | 이 사례에서 조건 준수 개선 확인 |
| 조사 자료 3문장 요약 | 대상·한계를 적절히 보존 | 첫 시도는 근거를 별도로 늘려 분량 부담, 자원 참여 집단 표현이 모호했음 | 첫 시도는 개선으로 판정하지 않음 |
| 수정한 요약 | 앞의 일반 결과를 기준으로 비교 | 3개 요약 문장 안에 근거를 연결. 모집 방식과 집단 구분 지시 강화 | 문제 수정 확인. 전반적 우위는 미확정 |
| 퀴즈 한 문제씩, 정답 대기 | 첫 문제만 제시하고 정답 대기 | 첫 문제만 제시하고 정답 대기 | 두 방식 모두 통과 |

원본 요청·응답은 `qa/gemini/results.json`, 수정 요약은 `qa/gemini/revised-summary.json`에 있습니다. 출력 예제는 항상 유리하지 않았습니다. 첫 요약에서 불필요하게 길어지는 문제를 확인해 기본 예제를 제거하고 형식 제약을 강화했습니다.

## 화면별 확인

- 홈: Askit 원본 로고, 작업 선택, 활용 방법, 선택적인 학생 혜택. 실제 학생이 올린 것처럼 만든 게시글 없음.
- 만들기: 임시 저장, 최소 입력, 직접 입력 선택과 빈칸 오류, 조건 우선순위, 자료 전달 방식 전환.
- 결과: 수정 내용 반영, 복사+Gemini 새 탭, 팝업 차단 시 별도 링크, 복사 권한 거절 시 직접 선택. Gemini에 자동 전송된다는 표현 없음.
- 보관함: 저장·재진입·수정·삭제, 다른 주제로 재사용. 브라우저 한정 저장임을 설명.
- Google 활용 방법: 작업에 따라 Gemini, NotebookLM, Deep Research, Flow로 연결. 계정별 이용 조건을 확인하도록 안내.
- 학생 혜택: 버튼을 위로 이동하고 불필요한 추천 관계 설명 삭제. 무료 기간 이후 유료 전환 조건은 유지. 안내 기한이 지나면 고정 무료 문구 대신 현재 조건 확인 화면으로 전환.
- 커뮤니티: 두 브라우저에서 공유 응답을 모사해 글/이미지/댓글/답글/좋아요/저장/신고/수정/삭제 확인. 로그인 전 작업으로 복귀하고 글 초안을 보존. 실제 서버 개통 전에는 닫힘 상태.

첫 화면 글꼴 전송은 전체 약 2MB 대신 UI 전용 약 93KB를 우선 사용합니다. UI 밖의 글자는 전체 글꼴로 표시하며 `font-display: swap`으로 글꼴 다운로드가 읽기를 막지 않게 했습니다. 실사용 네트워크 성능 수치로 해석하지 않습니다.

## 검수 범위의 한계와 개통 조건

정적 웹과 프롬프트 기능은 배포 가능한 파일로 준비했습니다. 공유형 커뮤니티는 연결 코드와 데이터/저장소 권한 구성이 완료된 상태이며, 실서비스 연결 완료는 아닙니다. Supabase 프로젝트·메일 발송·운영자 연락처를 설정하고 실제 두 계정으로 확인한 뒤 개통해야 합니다. Gemini API와 Vercel 배포는 아직 수행하지 않았습니다.

실제 대학생 참여 0명. 실제 iOS/Android 기기, 스크린리더 전체 탐색, 로그인 계정별 Google 기능, 결제/학생 인증, 가입 완료 집계는 미검증입니다. 자동 접근성 검사 통과는 전체 접근성 인증이 아닙니다. 학생 혜택 링크 클릭을 가입 완료로 집계하지 않습니다.
