# Askit 이용 통계

## 집계 기준과 합격 조건

- 방문자: 선택 기간에 실제 화면을 연 서로 다른 자사 쿠키 식별값. 사람 수가 아닌 브라우저 수이며, 쿠키 삭제·다른 기기는 별도 방문자다.
- 방문: 30분 동안 활동이 없으면 새 방문. 새로고침·탭 이동은 화면 조회로만 추가한다.
- 제작 성공: 서버가 결과를 검증한 뒤 결과 화면에 표시된 프롬프트. 서버 준비 완료, 추가 질문, 실패, 기본 프롬프트는 따로 집계한다.
- 복사: Clipboard API가 성공한 횟수. 수동 선택과 복사 실패는 제외한다. 재시도 전송은 같은 이벤트 ID로 중복 제거한다.
- Google AI 이동: 지원 도구 링크를 열도록 브라우저에 전달한 횟수. 외부 페이지 로드·로그인·생성 완료를 뜻하지 않는다. 팝업 차단은 별도 기록한다.
- 학생 혜택: 실제 외부 신청 링크 활성화 횟수. 내부 안내 페이지 조회 및 가입 완료와 구분한다.
- 운영자·검수 계정, 검수 링크, 미리보기 배포, 알려진 크롤러를 실제 이용에서 제외한다. 운영용 브라우저는 과거 기록까지 제외한다.
- 통계는 서버에서 검증한 운영자 계정만 조회한다. 개인 입력·파일·이메일·IP 원문은 통계에 저장하지 않는다.
- 집계 시작 전 기록은 복원하거나 기존 비용 요청과 합산하지 않는다. 원시 기록은 62일 보관하며 기존 정리 작업에서 삭제한다.

## 검수 루브릭

모든 항목 통과 전 배포 완료로 보지 않는다.

1. 정상 방문·제작·복사·외부 이동·혜택 링크 동작과 DB 기록이 일치한다.
2. 같은 이벤트 재전송, 새로고침, 결과 다시 열기로 성공 횟수가 중복되지 않는다.
3. 복사 실패·팝업 차단·추가 질문·기본 결과가 제작 성공에 섞이지 않는다.
4. 검수 이벤트는 운영 화면에서 확인되지만 실제 이용 숫자를 올리지 않는다.
5. 비로그인·일반 사용자에게 통계와 원시 이벤트 접근이 거부된다.
6. 통신 실패 시 제한된 재시도로 복구하며 제작·복사·이동을 가로막지 않는다.
7. 한국 시간 날짜 범위, CSV와 화면 합계, 모바일 표 표시가 일치한다.

## 남는 한계

브라우저 종료 전 통신 실패, 저장소 차단, 자동화의 일반 브라우저 위장은 완벽하게 판별할 수 없다. 수치에는 측정 범위와 정의를 함께 표시하며 추정 방문자를 실제 사람 수로 표현하지 않는다. 다른 기기의 운영 검수는 반드시 검수 시작 링크로 열어야 한다.
