# 프롬프트 개편 기준 · 실행 전 정의

2026-11-09. 기존 7회 결과와 새 실험을 섞지 않는다. 조합 코드의 테스트 통과, 모델 응답의 기준 통과, 실제 이용자의 편의는 별개의 검증이다.

## 입력 분류

| 분류 | 언제 필요한가 | 화면 원칙 | 반영 방법 |
|---|---|---|---|
| 작업·결과물 | 모든 작업 | 작업 선택 + 한 줄 설명. 자료 요약은 주제 입력 생략 | 작업별 결과 계약 |
| 자료·원본 | 원문 요약·문제 출제·기존 결과 수정 | 붙여넣기/첨부/외부에서 첨부 중 선택 | 실제 자료 없으면 생성 대기 |
| 파일의 용도 | 파일을 고른 경우에만 | 근거/과제 안내/디자인/원본/형식/직접 설명 | 파일별 번호·이름·용도·참고할 부분 연결 |
| 과제 조건 | 과제 지시문이 있는 경우 | 붙여넣기 한 칸. 선택 기본값보다 우선 | 충돌한 동급 조건은 확인 질문 하나 |
| 양·크기 | 제한이 있는 경우 | 시간과 장수, 유형과 문항 수를 독립적으로 | 합계·개수 검산 |
| 청중·이해도 | 설명 난이도·설득에 영향이 있을 때 | 관련 작업의 선택 항목 | 표현 수준·구체성 조정 |
| 시각 기준 | 이미지·슬라이드·영상 | 비율, 스타일, 정확한 문구, 유지/변경 요소 | 시각 참조의 내용 오염 방지 |
| 근거 범위 | 모든 사실 작업 | 자동 적용. 별도 설문 없음 | 원문 제한/실제 검색 여부/불확실성 구분 |

필수 정보가 아닌 학교·학년·전공을 일괄 요구하지 않는다. 임의로 묶은 ‘10분·8장’ 같은 선택지는 폐지한다. 모든 선택 항목은 직접 입력을 지원하며 빈 항목은 숨은 조건으로 생성하지 않는다.

## 출시 판정

평균 점수로 치명적인 실패를 감추지 않는다. 각 사례의 관찰 가능한 조건을 모두 만족하면 그 실행을 통과로 판정한다. 파일을 실제로 보지 않았는데 본 것처럼 답하거나, 없는 출처·생성물을 만든 경우는 즉시 실패다. 같은 사례를 독립 새 대화에서 반복한다. 일반 요청에도 같은 사용자 정보를 전달하며, 구조화 자체의 효과와 입력 정보량의 효과를 혼동하지 않는다.

| 항목 | 통과 기준 |
|---|---|
| 조건 준수 | 명시한 개수·시간·형식·언어 일치. 시간은 직접 합산 |
| 사실 충실성 | 제공한 집단·기간·수치·한계 보존. 없는 근거 추가 없음. 확인되지 않은 원인·효과는 해당 문장에 가정·확인 필요를 표시하며 마지막 주석만으로 통과시키지 않음 |
| 자료 구분 | 디자인·형식 파일의 내용을 새 과제의 사실로 사용하지 않음 |
| 시각 수정 | 수정 대상만 변경하고 유지 요소 보존. 결과 이미지를 직접 확인 |
| 대화 부담 | 충분한 정보가 있으면 바로 결과. 핵심 누락/충돌 때만 질문 하나 |
| 결과 정직성 | 미첨부 파일 추정, 가짜 PPTX·이미지 생성 완료 없음 |
| 입력 편의 | 기본 경로에서 긴 추가 설문 없음. 첨부 작업은 관련 조작만 추가 |
| 실패 복구 | 파일 오류·저장 거절·새로고침·다운로드 실패를 성공으로 표시하지 않음 |

텍스트의 고정 사례와 세부 기준은 `qa/prompt-v2/cases.json`에 먼저 고정한다. 실패하면 원인·수정·재검사 결과를 별도로 기록한다. 실제 모델명/계정/도구 상태를 기록하며, 소수의 반복 통과를 전체 과제의 일반적 우위로 해석하지 않는다. 평가는 개발자가 수행하며 독립 평가자나 대학생 사용자 실험이 아니다.

## 공식 근거

- [Gemini 프롬프트 전략](https://ai.google.dev/gemini-api/docs/prompting-strategies): 명확한 목적·제약, 일관된 구분, 멀티모달 입력 연결, 긴 자료 뒤 구체적 요청.
- [이미지 생성 가이드](https://ai.google.dev/gemini-api/docs/image-generation): 장면·목적·구도, 정확한 문구, 참조 이미지의 보존/변경 범위, 반복 수정.
- [이미지 이해](https://ai.google.dev/gemini-api/docs/image-understanding): 여러 이미지의 연결과 읽을 수 있는 자료 품질.
- [Gemini 파일 첨부](https://support.google.com/gemini/answer/14903178?hl=ko): 실제 파일 첨부 및 로그인 필요. Askit에 고른 파일은 Gemini로 자동 이전되지 않음.
- [Canvas](https://support.google.com/gemini/answer/16047321?hl=ko): 슬라이드 형식을 명시하고 파일/이미지를 함께 제공할 수 있음. 실제 이용 기능과 결과 생성은 계정·도구에서 확인.

Askit의 5개/20MB/합계50MB는 브라우저 보관을 위한 자체 제한이며 Gemini 서비스의 업로드 한도와 다르다.
