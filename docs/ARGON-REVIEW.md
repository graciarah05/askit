# Askit v1.2 — Argon 연결과 실제 품질 검증

2026-11-10. 최종 프롬프트 규칙: `argon-editor-v4-2026-11-10`.

## 결론

사용자가 Vercel에 저장한 키로 `gemini-4-argon` 연결을 완료했다. 실제 서비스 화면에서 요청문 생성, 반영 조건 표시, 원문과 복사 내용 일치, 저장 후 재열기를 확인했다. [수정된 Preview](https://askit-nmky4z2oq-graciarah05-2261s-projects.vercel.app)는 Vercel 로그인이 필요하다. 실험용 API는 최종 배포에서 껐다.

품질 판정은 **조건부**다. 발표의 사실/가정 구분, 참고 파일 용도 분리, 충돌 질문, 영상의 근거 없는 대본 표현에서 개선을 확인했다. 요약·퀴즈는 일반 요청도 잘 수행하여 Askit의 우위가 입증되지 않았다. 자료 없는 학교별 세부 기준, 실제 학생의 편의, 이미지·PPT 완성품 품질은 검증 완료로 표시하지 않는다.

## 무엇을 비교했는가

- 합성 사례 8종의 비교·회귀 기록 25건, 실제 모델 호출 39회. 한 기록에 프롬프트 작성과 최종 답변 작성이 각각 포함될 수 있다.
- 같은 입력으로 직접 요청, 기존 고정 규칙, Askit Argon 편집, 일반적인 '프롬프트 개선해 줘' 요청을 비교했다. 모든 사례에 네 경로를 전수 실행한 것은 아니다.
- 최종 답변은 동일한 Argon LOW로 생성했다. 프롬프트 편집은 LOW와 MEDIUM을 두 사례에서 비교했다.
- 서비스 화면에서 별도 생성 2회를 확인했다. 이 화면 검증은 최종 과제 답변 평가와 구분한다.
- 실패를 삭제하지 않았다. 텍스트 첨부 검증 오류 1건과 영상 내용 실패, 부분 충족 사례도 원문에 남겼다.
- 판정자는 이 작업을 수행한 에이전트다. 맹검·독립 평가·학생 사용성 실험이 아니다. 루브릭의 배점은 운영 기준이며 과학적으로 확정된 보편 기준이 아니다.

## 실제로 발견한 문제와 조치

| 사례 | 관찰 | 조치와 판정 |
|---|---|---|
| 6장·7분 발표 | 직접 요청과 일반 개선 요청은 미확인 시험 기간 현황 등을 사실형으로 제시 | Askit/기존 규칙 경로는 확인할 질문·가정으로 구분. 같은 입력에서 개선 관찰. 모든 발표에 대한 일반화 불가 |
| 자료 3문장 요약 | Askit, 기존 방식, 직접 요청, 일반 개선 요청 모두 주요 수치·표본 범위·미조사 항목 보존 | 동등하게 양호. 자료 번호가 없는 직접 요청을 그 이유만으로 실패 처리하지 않음 |
| 한 문제씩 퀴즈 | 네 경로 모두 첫 문항만 제시하고 정답을 미리 공개하지 않음 | 명확한 품질 우위 미입증 |
| 텍스트 디자인 참고 | v1 서버 검증기가 실제 전송된 TXT의 관찰 결과를 거부해 502 | 텍스트 파일도 분석된 자료 목록에 포함. v2·v3·v4 실제 호출 성공. 이 서버 오류를 모델 품질 실패와 구분 |
| 템플릿 내용과 디자인 | 색상·배치는 반영하고 ACME·52%·120만을 새 과제 사실로 옮기지 않음 | 파일 용도 구분 통과. 학교별 근거가 없는 일반 분리배출 수칙 표현은 부분 충족으로 보수적으로 판정. 실제 안내문으로 쓰기 전 해당 학교 근거 필요 |
| 필수 조건 충돌 | v1은 5장/8장 충돌을 찾았지만 '두 버전 모두'를 추가 선택지로 제시 | v3는 두 기준 중 하나만 묻고 대기. 불필요한 새 작업 선택지 제거 |
| 이미지 원본 누락 | 원본을 보지 않았다고 밝히고 결과 생성 완료를 주장하지 않음 | 진행 방식까지 추가로 묻는 장황함은 부분 충족. 원본 없이 이미지를 완성했다고 하지 않은 점만 통과 |
| 실제 PNG 첨부 | 파란 원, 양옆 주황 정사각형, 흰 배경을 실제 입력에서 식별 | v2·v4에서 변경/유지 요소를 분리한 요청문 확인. 실제 수정 이미지 생성·픽셀 보존은 이 API 실험에서 미검증 |
| 43초·4장면 영상 | v3는 시간·장면 수·1인 촬영을 지켰지만 미확인 교내 정수기, 과장된 효과, 반복 빈칸을 대본에 넣음 | 불합격 기록 후 근거 규칙을 서버가 직접 보존하도록 보강. v4는 9+11+13+10초, 4장면 유지하며 대본의 문제 표현과 빈칸 제거. 선택적 할인 확인 제안은 여전히 불필요하여 부담 항목 감점 |

서버가 프롬프트 뒤에 원문과 파일 역할을 보존해 붙이므로 AI가 원문을 요약하면서 숫자를 바꾼 결과를 다음 단계의 원문으로 사용하지 않는다. 자료와 마지막 실행 요청을 분리했고, 이미지/PDF는 요청 지시보다 앞에 전송한다. 중요한 근거 규칙은 편집 모델이 생략하더라도 최종 요청에 남는다.

## 대기시간과 비용

아래는 **성공한 Askit 프롬프트 작성 단계**의 서버 측 API 시간이다. 브라우저 전체 왕복, 학생이 Gemini에서 얻는 최종 결과 시간과 다르다. 여러 수정 버전과 서로 다른 사례를 합친 작은 표본이다.

| 설정 | 횟수 | 중앙값 | 범위 | 1회 비용 중앙값 |
|---|---:|---:|---:|---:|
| LOW | 13 | 18.709초 | 9.617–35.146초 | $0.009654 |
| MEDIUM | 2 | 32.997초 | 20.928–45.065초 | $0.008322 |

MEDIUM의 두 비용이 낮게 나왔다고 더 저렴한 모드라고 해석하지 않는다. 실제 생성 길이와 사례가 다르다. 두 대응 사례에서 MEDIUM의 뚜렷한 품질 개선은 보이지 않았고 대기는 길어 기본값을 LOW로 유지했다. 표본이 작으므로 p95나 일반적인 응답 보장을 제시하지 않는다.

잠정 목표인 작성 중앙값 15초는 **미달**이다. 대기 시간 표시, 한 번 눌러 기본 프롬프트 보기, 입력 보존, 자동 재시도 금지로 불필요한 대기와 중복 비용을 줄였다. 다음 최적화는 동일한 긴 자료에서 입력 중복 감소·출력 길이를 비교하는 실험이며, 아직 효과를 입증했다고 쓰지 않는다.

- 비교 실험 39회: **$0.306608** 추정.
- 서비스 화면 검증 2회: **$0.017670** 추정.
- 확보한 사용량 기록 41회 합계: **$0.324278** 추정.
- 최종 배포 화면의 마지막 생성: **29.198초 / $0.009226**.

[Google 공식 Standard 가격](https://ai.google.dev/gemini-api/docs/pricing)에 보고된 입력·출력·추론·캐시 사용량을 적용한 값이다. 확정 청구액, 세금, Vercel 비용은 포함하지 않는다. 실패한 텍스트 첨부 호출의 사용량도 합계에 포함했다. 운영 설정이나 취소 때문에 사용량을 받지 못한 다른 호출이 있다면 이 합계로 전체 청구서를 대신할 수 없다.

## 구현·화면 검사

- 코드 검사 **92개 통과**: 기존 조합 규칙, 입력 형식·파일 크기·실제 형식, 출력 검증, 원문 보존, 비용 계산, 오류·중복 요청·키 비노출·Production 차단 등.
- UI 검수 기록 **11건**: 성공·오류·기본 방식 전환·확인 질문·파일 분석 선택·첨부 취소·실제 생성/복사/저장·390px 입력 화면·실험 기능 종료.
- 실패·지연·파일 전송 UI 일부는 고정된 검사용 응답으로 검사했다. 이를 실제 모델 정확성 증거로 섞지 않는다.
- 실제 배포 결과 화면은 Chrome에서 확인했다. Chrome의 390px 설정은 실제 DOM 폭이 바뀌지 않아 모바일 증거로 인정하지 않았다. 동일 프런트엔드의 로컬 IAB 검사에서 실제 폭과 문서 폭이 모두 390px임을 확인했다.
- 이번에 바뀌지 않은 커뮤니티의 기존 검사나 과거 40개 화면 조합을 새 버전에서 다시 실행했다고 집계하지 않았다.

## 남은 한계

1. 자료 없는 사실형 결과를 완전히 막았다는 보장은 없다. 특히 학교별 규정·정책 안내는 실제 근거를 추가하고 검수해야 한다.
2. 대학생 대상 맹검 결과 평가·작업 완료 시간·입력 피로·재방문율 조사는 아직 없다. 대학생에게 지속적으로 필요하다는 증거를 모델 응답만으로 만들지 않는다.
3. 이미지 이해 2건은 이미지 생성의 시각 품질이나 복잡한 한국어 텍스트, PPTX 디자인 재현을 보장하지 않는다. PDF 처리 형식은 구현했지만 실제 PDF 샘플의 품질은 이번 실험에 포함되지 않았다.
4. 실제 Gemini 앱의 선택 모델·요금제·도구가 다르면 여기의 Argon 최종 결과 실험과 달라질 수 있다.
5. 불특정 공개 사용을 위한 지속적인 호출 제한·예산 상한과 실제 공유 커뮤니티 연결은 별도 작업으로 남는다. 현재는 인증된 Preview이며 공개 Production의 유료 호출은 닫혀 있다.
